# Student Performance Trend Analysis

## About the Project
The Student Performance Trend Analysis system is designed to compare students' marks across two examinations. It calculates averages and identifies improvements, declines, or unchanged performance in different subjects.

## Objectives
- Store subject names and examination marks.
- Compare marks from two examinations.
- Identify improvements and declines.
- Calculate examination averages.
- Analyse overall academic performance.

## Concepts Used
- Variables and data types
- Lists
- For loop
- Conditional statements
- Arithmetic operators

## How the Program Works
1. The user enters the number of subjects.
2. Subject names are collected.
3. Marks for the first and second examinations are entered.
4. The program compares the marks of each subject.
5. Performance is classified as improved, declined, or unchanged.
6. The average marks of both examinations are calculated.
7. The overall performance is displayed.

## Conclusion
This project demonstrates how Python lists, loops, and conditional statements can be used to analyse and compare student academic performance.
